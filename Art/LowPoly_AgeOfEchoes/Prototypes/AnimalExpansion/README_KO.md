# 동물 확장 모델 검토

여우(`Fox`), 스라소니(`Lynx`), 들소(`Bison`), 양(`Sheep`)의 로우폴리 형태를 검토하는 프로토타입이다. 기존 동물과 구별되는 실루엣·체형·귀·뿔·꼬리와 자연스러운 네 다리 비율을 먼저 확인한다.

형태 승인 후 네 종을 리깅하고 키프레임 애니메이션을 만들었다. 정적 원본은 이 폴더에, 리깅 원본과 애니메이션 GLB는 `Animated/`에 있다. 월드 출현과 전투 연결은 별도 적용 단계다.

## 좌표와 전달 규칙

- 편집 가능한 원본은 `AnimalExpansion_Meshes.blend`다.
- Blender 원본은 Z-up, 앞 방향은 -Y다. 검토용 네 컬렉션의 X 위치는 Fox -6, Lynx -2, Bison 2, Sheep 6이다.
- 개별 GLB는 종별 정렬 오프셋을 제거한 원점 기준으로 내보낸다. glTF 축 변환으로 GLB는 +Y 위, +Z 앞을 사용한다.
- 컬렉션은 `MOB_{Species}`, 메시 오브젝트와 메시 데이터는 `SM_MOB_{Species}_{Part}`, 재질은 `MAT_{Species}_{Material}` 형식이다. 종 구분에는 `Fox`, `Lynx`, `Bison`, `Sheep` 이름을 유지한다.
- `AnimalExpansion_Preview.png`는 사선, `AnimalExpansion_Side.png`는 측면 비교다. 각 동물을 보기 좋게 확대한 이미지이므로 종 사이 실제 크기 비율을 나타내지 않는다. 형태 검토용이며 게임 적용이나 애니메이션 검증 결과가 아니다.
- `AnimalExpansion_HindLegs_Compare.png`는 뒷다리 수정 전(왼쪽)과 후(오른쪽)를 종별로 확대해 비교한다.

## 파일과 메시 수

눈 형태와 뒷다리를 보정한 개별 GLB를 다시 판독한 결과다. 뒷다리 수정 전과 메시 이름·수 및 삼각형 수는 같다.

| 동물 | 개별 GLB | 이름 있는 메시 수 | 삼각형 수 |
|---|---|---:|---:|
| 여우 | `MOB_Fox.glb` | 22 | 1,480 |
| 스라소니 | `MOB_Lynx.glb` | 26 | 1,620 |
| 들소 | `MOB_Bison.glb` | 34 | 2,172 |
| 양 | `MOB_Sheep.glb` | 27 | 1,668 |

## 확인 상태

사선·측면 실제 모델 렌더를 검토하고 눈의 돌출을 보정했다. 이어 네 종 모두 뒷다리의 무릎을 몸통 가까이 올리고 허벅지 시작 부분을 몸 안쪽으로 이어 큰 이중 꺾임을 줄였다. 하퇴는 거의 수직으로 세우고 발은 엉덩이 아래쪽으로 옮겼다. 수정 후 사선·측면 렌더와 전후 비교 이미지를 다시 확인했다.

`AnimalExpansion_Meshes.blend`와 정적 GLB의 메시 이름·수와 삼각형 수 유지, GLB의 지면 Y=0을 확인했다.

## 리깅 및 애니메이션

- `Animated/AnimalExpansion_Rigged.blend`에 네 리그와 편집 가능한 액션이 들어 있다. Blender 액션 이름은 `Fox__Walk`처럼 종을 앞에 붙이고, GLB에서는 `Walk`처럼 공통 클립 이름을 쓴다.
- 종별 배포 파일은 `Animated/MOB_Fox_Rigged.glb`, `MOB_Lynx_Rigged.glb`, `MOB_Bison_Rigged.glb`, `MOB_Sheep_Rigged.glb`다. 종마다 21개 뼈, 30 fps 위치·쿼터니언 키프레임, 정점당 최대 3개 웨이트를 사용한다. 스킨 메시 파트에 `SKM_MOB_{Species}_{Part}` 이름과 기존 파트 ID를 연결했다.
- 걷기·달리기·점프·왼쪽 90도 회전의 실제 리그 렌더는 `Animated/`의 `Walk.gif`, `Run.gif`, `Jump.gif`, `Turn_L90.gif`에서 비교할 수 있다. GIF는 종별 클립을 한 주기에 맞춰 표시하며 GLB에는 종마다 다른 재생 시간이 들어 있다.

| 클립 | 재생 |
|---|---|
| `Idle`, `Walk`, `Run` | 반복 |
| `Turn_L45`, `Turn_R45`, `Turn_L90`, `Turn_R90` | 제자리 회전 |
| `WalkTurn_L45`, `WalkTurn_R45`, `RunTurn_L45`, `RunTurn_R45` | 이동 중 회전 |
| `Jump` | 준비·도약·공중·착지 |
| `JumpStart`, `JumpLoop`, `JumpLand` | 물리 이동에 연결할 분리형 점프. `JumpLoop` 반복 |
| `Attack`, `Hit`, `Death` | 공격·피격·쓰러짐 |

`Walk`와 `Run`은 제자리 클립이다. Blender 액션의 `nominal_speed_mps`에 맞춰 게임 이동 속도나 클립 배속을 조정하면 디딘 발의 미끄러짐을 줄일 수 있다. 회전 클립에는 루트 회전이 들어 있으므로 적용 시 같은 회전을 액터에 중복 적용하지 않는다. `Jump`에는 루트의 수직 이동이 있고, 분리형 점프는 수직 이동을 물리 쪽에서 적용한다.

GLB 네 파일에서 파트·삼각형 수, 스킨, 정규화 웨이트, 18개 클립의 키프레임 및 반복 경계 포즈를 검사했다. Blender에서 걷기·달리기 중 발 들기와 접지, 점프의 이륙·착지, 여덟 회전 클립의 최종 각도를 검사했다. 검사한 키프레임에서 발바닥의 지면 관통은 관측되지 않았다.

### 걷기 관절 보정

앞다리의 주 굽힘점을 팔꿈치 위치로 올렸다. `Walk`와 좌우 `WalkTurn_L45`·`WalkTurn_R45`에서 팔꿈치와 뒷발목의 굽힘 방향을 진행 방향 기준으로 고정하고 관절 사이의 뼈 길이와 발 디딤 위치를 유지한다. 보폭과 발을 들어 올리는 높이도 조금 줄였다. 새 걷기 기준 속도는 여우 약 0.45, 스라소니 0.43, 들소 0.38, 양 0.31 m/s다.

네 종의 걷기와 걷는 중 회전 전체 1,740개 다리 포즈에서 관절 방향과 연결을 검사했다. 원본 리그와 종별 GLB를 다시 내보내고 GIF 네 개를 갱신했다.
