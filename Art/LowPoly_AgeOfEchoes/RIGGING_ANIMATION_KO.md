# 사람·몹 리깅 및 키프레임 애니메이션 인계

게임 코드·프로젝트·빌드·AI는 수정하지 않았다. 이 작업의 결과는 모델, 스키닝, 뼈대와 키프레임 클립이다. 실제 저장 NPC ID와 외형 조합의 연결은 이전과 같이 다음 적용 작업에서 구현한다.

## 사용할 파일

- `AgeOfEchoes_Characters_Rigged.blend`: 사람 공용 파트 37개와 몹 7종의 리깅·애니메이션 원본.
- `Exports/Rigged/NPC_Modular_Rigged.glb`: 공통 사람 뼈대 1개와 파트 37개, 애니메이션 18개. 여러 의상과 머리가 같은 위치에 들어 있는 **조립용 라이브러리**이며, 전부 동시에 표시하는 완성 캐릭터가 아니다.
- `Exports/Rigged/NPC_Resident_Animated.glb`: 바로 재생할 수 있는 주민 조립 예시 1명과 애니메이션 18개.
- `Exports/Rigged/MOB_01_Wolf.glb` ~ `MOB_07_AshenRevenant.glb`: 종별 뼈대·스킨·애니메이션 18개를 포함한 파일 7개.
- `Catalog/rig_catalog.json`: 사람 파트의 원래 ID ↔ 리깅된 ID, 슬롯 번호, 뼈 이름·부모·기준 좌표.
- `Catalog/animation_catalog.json`: 뼈대별 정확한 클립 이름, 실제 길이, 반복 여부, 회전량과 기준 이동 속도.
- `Catalog/creature_catalog.json`: 고정 종 인덱스, 분류, 보행 방식, 메시 이름과 GLB 경로.
- `Catalog/shared_geometry_aliases.json`: 망자에서 공유하는 사람 메시 7개의 참조 관계. 망자의 색은 오브젝트 재질로 교체했다.
- `Catalog/animation_transition_contract.json`: 다른 작업에서 사용할 전환·루트 이동 규칙.
- `Catalog/rig_animation_validation.json`, `locomotion_pose_audit.json`: 최종 스킨·루프·내보내기·접지 검사 결과.
- `Catalog/turn_contact_audit.json`: 제자리 회전의 발 디딤 높이 검사. 4족의 90° 회전은 발마다 45°씩 두 번 나누어 디디며 발바닥 방향을 유지한다.

기존 정적 원본 `AgeOfEchoes_LowPoly_Modular.blend`와 정적 GLB는 보존했다. 리깅된 파일의 사람 파트는 `SKM_NPC_...` 이름을 사용하며, 슬롯별 기존 인덱스는 변경하지 않았다. `source_asset_id`로 정적 `SM_NPC_...` 에셋을 추적할 수 있다.

## 4족 뒷다리 수정 (리그 revision 2)

사용자가 제공한 서 있는 개의 옆모습을 기준으로 늑대의 실루엣을 수정하고, 멧돼지·곰·사슴·염소·토끼에도 종별 체형에 맞춰 적용했다. 허벅지의 노출 길이와 부피를 줄여 엉덩이 쪽에 붙였고, 크게 튀어나오던 중간 꺾임을 줄였다. 가늘어진 아래 다리와 별도의 발목 구간이 발로 이어진다. 토끼의 체형에 필요한 뒷다리 근육은 유지했다.

4족의 뒷다리를 `hind_upper` → `hind_lower` → `hind_hock` → `hind_foot`으로 변경했다. 좌우 발목 뼈 2개가 추가되어 19개에서 21개 뼈가 됐다. 6종의 18개 클립을 새 기준 자세와 역바인드 행렬에 맞춰 다시 구웠다. 멧돼지는 90°에 세 번, 45°에 두 번 짧게 디디며, 달리기에서는 골반 높이를 소폭 보정해 접지를 유지한다.

메시 이름·종 번호·파일 이름·클립 이름은 유지했다. 스켈레톤과 바인드 행렬이 변경됐으므로 적용 작업에서는 기존 4족의 뼈 인덱스/역바인드 캐시를 재사용하지 말고 새 GLB에서 읽어야 한다. 사람과 망자의 뼈대·파트 인덱스는 변경하지 않았다.

`Previews/Rigged/04_Quadruped_Hind_Before_After.png`에서 6종 전체를, `05_Wolf_Hind_Before_After.png`에서 늑대를 크게 비교할 수 있다. Walk/Run/Jump/Turn_L90 GIF와 전체 배치·달리기 포즈 이미지도 갱신했다. `Catalog/quadruped_hind_revision.json`과 기존 접지·루프 검사 파일에 수정 후 결과를 기록했다.

## 뼈대와 스키닝

사람과 망자는 21개 뼈, 동물은 종별 21개 뼈를 사용한다. 사람의 골반·몸통·머리, 양팔·양다리·손발, 망토·로브 보조 뼈를 포함한다. 동물에는 골반·등·목·머리·턱·꼬리와 앞다리의 상부/하부/발과 뒷다리의 상부/하부/발목/발 뼈가 있다. 동물은 종마다 비율이 다르므로 뼈 이름이 같아도 역바인드 행렬을 다른 종에 그대로 쓰지 않는다.

모든 파트에 정규화된 버텍스 웨이트를 넣었으며 정점당 최대 영향 뼈 수는 4개다. 무기·방패·등불은 손뼈, 머리·헤어·모자는 머리뼈, 배낭·화살통은 가슴뼈에 연결했다. 망토와 로브는 보조 뼈를 사용한다. 로브는 달리기 중 무릎을 따라 움직이도록 보정했다. 천은 뼈 기반 변형이며 물리 천 시뮬레이션은 아니다.

사람은 성별과 의상마다 뼈대를 다시 만들지 않는다. 필요한 파트만 동일한 뼈대에 조립한다. 망자도 사람의 메시 7개를 재사용하고 색상·자세·클립으로 구별했다. 신규 동물 메시 데이터는 6개다. 검토용 복제 캐릭터도 원본 메시 데이터를 공유한다.

모든 최종 애니메이션은 30fps의 위치·쿼터니언 회전 키프레임이다. 곡선은 매 프레임 샘플링한 LINEAR 키이며 발 접지 사이에 베지어 오버슈트가 생기지 않는다. 최종 스켈레톤은 IK 제약·드라이버·외부 플러그인에 의존하지 않는다. Blender NLA 트랙과 GLB 애니메이션 이름을 동일하게 맞췄다.

## 각 뼈대에 들어 있는 클립 18개

| 이름 | 용도 | 반복 |
|---|---|---|
| Idle | 대기·작은 호흡/보조 움직임 | O |
| Walk | 보행 | O |
| Run | 달리기 | O |
| Turn_L45, Turn_R45 | 제자리 45° 회전, 발 교대 디딤 | X |
| Turn_L90, Turn_R90 | 제자리 90° 회전, 발 교대 디딤 | X |
| WalkTurn_L45, WalkTurn_R45 | 보행 한 주기에 걸친 45° 회전 | X |
| RunTurn_L45, RunTurn_R45 | 달리기 한 주기에 걸친 45° 회전 | X |
| Jump | 준비·도약·공중·착지·회복의 완결형 점프 | X |
| JumpStart | 분리형 점프의 준비·이륙 | X |
| JumpLoop | 분리형 점프의 공중 유지 | O |
| JumpLand | 분리형 점프의 착지·회복 | X |
| Attack | 사람의 휘두르기, 동물별 물기/앞발/머리 동작 | X |
| Hit | 피격 반응 | X |
| Death | 주저앉음/무너짐 | X |

8개 뼈대 × 18개 = 총 144개 키프레임 액션이다. GLB 9개는 사람 라이브러리·주민 예시·몹 7종이며, 주민 예시는 공통 사람 액션을 재사용한다. 종별 보행·달리기·점프 길이는 다르므로 사람의 프레임 수를 모든 몹에 강제로 적용하지 않는다. 실제 값은 `animation_catalog.json`을 기준으로 한다.

## 이동·회전·점프 적용 규칙

- 기준 좌표는 Blender +Z 위/-Y 앞, GLB +Y 위/+Z 앞이다. 루트 양의 회전은 캐릭터의 왼쪽 회전이다. 원점은 지면이며 단위는 미터다.
- Walk/Run은 XY 제자리 클립이다. 게임에서 캐릭터를 앞으로 이동해야 한다. 각 클립의 `nominal_speed_mps`에 맞춰 이동 속도 또는 재생 배속을 조정해야 접지 구간에서 발이 미끄러지지 않는다. 지형 경사에 대한 런타임 발 IK는 이 에셋 범위에 포함하지 않았다.
- 회전 클립에는 루트 뼈의 yaw 변화가 들어 있다. 게임 적용 시 루트 yaw를 추출해 액터에 적용하거나, 클립이 끝날 때 누적 회전량을 액터에 넘기고 루트 회전을 정리한다. 액터 yaw와 루트 yaw에 같은 회전을 중복 적용하지 않는다. 이후 Idle/Walk/Run과 전환할 때 이 누적 방향을 유지한다.
- 키프레임 사이 회전과 클립 사이 포즈 혼합에는 쿼터니언 보간을 사용한다. 전환 시간의 시작값은 Idle↔Walk 0.12초, Walk↔Run 0.10초, Turn 진입/복귀 0.10초, JumpStart/Loop/Land 0.06초다. 이 값은 적용 시 조정할 데이터이며 게임의 블렌드 트리를 구현하지 않았다.
- 완결형 Jump에는 루트의 수직 포물선이 있다. 이 클립을 사용하면 같은 수직 변위를 물리 이동으로 다시 더하지 않는다. 물리 기반 점프에는 수직 루트 이동이 없는 JumpStart → JumpLoop → JumpLand를 사용하고, 실제 이륙·착지 상태로 전환한다.
- 클립 끝 포즈와 다음 클립의 접지 시점을 맞춰 전환한다. 45°/90° 클립을 이어 붙이거나 재생 배속을 조절해 다른 회전량을 만드는 것은 다음 적용 작업에서 처리한다.

## 미리보기와 확인 범위

`Previews/Rigged/01_Seven_Creatures_Rigged.png`는 사람 1명과 몹 7종의 전체 모습이다. `02_Run_Key_Poses.png`는 사람·늑대의 달리기 포즈, `03_Clothing_Run_Deformation.png`는 주민·갑옷·궁수·로브의 변형 비교다.

`Walk.gif`, `Run.gif`, `Jump.gif`, `Turn_L90.gif`는 실제 뼈대와 스킨을 렌더링한 동작 비교다. 한 화면에서 접지 순서를 비교하기 위해 **종별 한 주기를 같은 길이로 정규화**했다. 실제 GLB의 종별 재생 시간은 바꾸지 않았다. GIF는 적용 데이터가 아니다.

검사한 항목은 웨이트 합·최대 영향 수·참조 뼈, GLB의 스킨과 18개 클립 이름, 반복 클립 처음/끝 뼈 행렬, Walk/Run과 제자리 회전의 접지 발목 높이다. 보행·달리기 접지 발목 높이 오차는 사람 약 0.5mm, 동물 최대 약 3.2mm였으며 회전은 최대 약 6.6mm였다. 반복 경계는 허용 오차 안에 맞았다. 이 수치는 평평한 지면에서의 뼈대 검사이며 게임 내 이동·회전·블렌딩 결과를 대신하지 않는다. 게임 빌드나 실행은 하지 않았다.
