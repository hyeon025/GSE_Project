# NPC·몬스터 피격 표시

## 결정과 이유

주민과 모든 종류의 몬스터가 공격받으면 기존 모델 전체를 잠깐 붉게 표시하고 원래 색으로 되돌린다. 주민별 외형과 모듈형 메시, 리깅, 키프레임은 그대로 사용한다. 빨간 GLB나 복제 메시를 추가하면 조합과 메모리가 늘어나므로 그리기 인스턴스에 피격 강도만 전달한다.

적용 모델은 주민, 야생동물 6종(늑대·멧돼지·곰·사슴·염소·토끼), 전투의 잿빛 망령(`MOB_AshenRevenant`)이다. 전투 역할 Raider는 멧돼지, Runner는 늑대, Archer는 잿빛 망령, Boss는 곰 모델을 사용하므로 몬스터의 고유 모델은 총 7종이다. 일반 전투와 스토리 전투는 같은 `LevelOneView` 표시 경로를 사용한다.

주민 `Life.hitFlash`, 야생동물 `hitFlash`, 전투 적 `flash`는 0.30초짜리 피격 타이머다. 실제 피해 때 다시 시작하며 기존 갱신 경로에서 줄어든다. 주민은 플레이어·다른 주민·위험 동물의 공격에, 동물은 `WorldCombat` 투사체와 `Wildlife::Attack` 직접 공격에, 전투 적은 `LevelOne`의 아군 투사체 명중에 연결한다. 주민 타이머는 저장하지 않고 불러올 때 0으로 초기화하며, 기존 저장 형식도 유지한다.

`GameScene`과 `LevelOneView`에서 `DrawRequest`로 전달한 강도는 일반 투영, GPU 캐시 재사용, 비동기 이전 포즈, 대체 캐릭터 렌더링 경로까지 전달한다. Boss 대체 모델은 그림자를 별도로 그리고 로컬 메시를 캐시해 같은 붉은색 처리를 사용한다. 일반 대체 모델도 `Person`에 피격 강도를 전달한다. 셰이더는 팔레트색과 고정 재질색을 모두 계산한 뒤 붉게 섞어 얼굴과 옷의 음영을 보존한다. 피격 강도는 포즈 캐시 키에 넣지 않고 기존 인스턴스의 `depth.w`를 사용해 인스턴스 크기 192바이트와 배칭을 유지한다.

## 확인 방법

게임에서 주민 가까이에서 `F`를 누르거나 대화의 공격을 선택한다. 주민끼리 전투하거나 위험 동물이 주민을 공격할 때도 확인한다. 위험 동물은 자동 사격, 초식동물은 `F` 수동 공격으로 확인하고 일반·스토리 전투에서도 적을 명중시킨다. 맞은 모델 전체가 붉어졌다가 약 0.30초 동안 원래 색으로 돌아와야 한다. 주변의 맞지 않은 NPC와 몬스터는 기존 색을 유지해야 한다.

## 검증 기록

- 기존 `WorldCombatTests`, `CharacterStyleTests`, `WildlifeTests` 컴파일 및 실행 통과. 동물 회귀 검사는 주민 168명·동물 42마리, 방향, 추격·도주, 피해·공격, 재등장, 과거 밀집 저장을 포함한다.
- 전체 NPC·몬스터 적용 변경 후 `WorldCombatTests`, `WildlifeTests`, `StoryTests`를 다시 컴파일·실행해 통과했다.
- `NpcHitFeedbackTests`, `WorldSimulationTests` 통과. 실제 피해, 거절된 공격, 타이머 감소·종료, 사망, 저장 형식 보존과 불러오기 초기화를 확인했다.
- 주민 `NpcHitRenderTests`의 실제 OpenGL 출력에서 붉어진 픽셀 28,891개를 확인했다. 정상→피격→정상 순서에서 원복 화면은 최초 화면과 픽셀 단위로 일치했다. 캐시 재사용, 비동기 이전 포즈, 고정 재질색, 부분 색 복귀를 검사했고 첫 메시 생성과 기본 HDR 후처리에서도 통과했다. HDR 원복 화면도 최초 화면과 픽셀 단위로 일치했다.
- 같은 렌더 검사에서 draw call은 3회로 유지됐다. 피격·원복 모두 메시 2개와 정점 메모리 174,144바이트를 재사용했으며 메시 캐시 미스와 생성은 0회였다. 인스턴스 업로드는 960바이트였다.
- `x64/npc-hit/normal-hit-restored.png`의 주민 정상·피격·원복 비교 화면도 직접 확인했다. 비교 이미지는 Git에서 제외되는 검증 출력이다.
- 코드 검토에서 발견한 위험 동물→주민 피해 경로 누락을 보완했다. 해당 주민 경로의 재검토 후 미해결 사항은 없다.
- `MonsterHitFeedbackTests`, `AllNpcHitRenderTests` 통과. 주민 40개 조합과 몬스터 7종, 실제 `Enemy` 표시의 전투 4역할, 실제 장면 콜백의 동물 6종, Boss 대체 모델의 위치·크기를 포함해 정상→피격→원복을 검사했다.
- 전종 렌더 검사는 MSAA 경계의 미세한 차이를 고려해 원복 오차를 채널별 최대 1/255까지 허용했다. 붉은색 변화는 별도로 최소 100~1,000픽셀 이상 확인했다. 전종 화면을 비트 단위로 완전히 같은 결과로 간주하지 않는다.
- `x64/npc-hit/all-monsters-normal-hit-restored.png`를 직접 확인했다. 늑대·멧돼지·곰·사슴·염소·토끼·잿빛 망령 순으로 정상·피격·원복이 표시되며, 이 이미지도 Git에서 제외되는 검증 출력이다.
- 전체 적용 후 Release 재빌드 성공. 최종 코드 검토에서 미해결 사항은 없다.

실 플레이 저장은 테스트 대상으로 덮어쓰지 않는다.

## 배운 점

피해는 주민 전투, 플레이어 직접 공격, 야생동물, 월드 투사체, 일반·스토리 전투에 나뉘어 있다. 피격 표현을 추가할 때 모델 목록과 함께 실제 체력 감소 경로, 원본 모델을 못 불러왔을 때의 대체 표시까지 확인해야 한다.
