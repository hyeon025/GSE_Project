# NPC 이동과 자유 시간

## 제자리 왕복 수정

기존 코드는 건물에 막히면 가장 가까운 도로 교차점과 임시 목적지를 다시 선택하고, 매 이동마다 먼저 가능한 회전 방향으로 걸었다. 같은 장애물의 양쪽을 번갈아 선택하거나 경유지로 되돌아가면 실제 목적지에 도달하지 못했다.

별도 출력 폴더의 이전 코드로 60개 집 입구에서 사냥터·명상터·마을 중심까지 이동시켰다. 잿빛 마을의 4·24·25·26번 lot(0부터 시작)에서 160초가 지나도 도착하지 못하는 경우 4개를 재현했다. 수정된 이동으로 같은 경우 모두 도착한다.

막히지 않은 목적지는 직선으로 이동하고, 막힌 경우 16단위 격자의 A*로 경유지를 계산해 유지한다. 경로는 충돌하지 않는 선분으로 단순화한다. 건물 모서리를 드문 위치 샘플로 검사하면 작은 교차를 놓칠 수 있어, 건물 사각형·자연물 원형 충돌체에 대해 이동 선분 전체를 검사한다. 목적지가 바뀌거나 경로가 막히면 다시 계산한다. 도달할 수 없는 곳은 잠시 기다린 후 재시도하며 좌우 회전을 반복하지 않는다. 일반 작업 지점은 반복 실패 시 같은 작업 구역 안의 다른 유효 지점을 고른다.

마을 사이 이동은 기존 마을 도로 연결을 따라가며, NPC별 작은 차선 차이를 준다. 계획 중인 마을 경유지는 도착할 때까지 유지한다. 기존 저장에서 건물 안에 남은 잘못된 좌표는 최초 초기화 때 안전한 집 입구 또는 마을 중심으로 복구한다. 정상 경로 이동 중에는 순간이동하지 않는다.

## 자연스러운 행동

- 사냥터·명상터·마을 도착 지점을 NPC마다 조금씩 다르게 선택한다. 일반 순찰은 시간에 따라 앞뒤로 바뀌는 두 지점 대신 유효한 순찰 지점을 하나 선택해 유지한다.
- 목표로 이동 중에는 목표를 유지한다. 자유 시간은 출발 전이나 도착한 뒤에 시작한다. 마을 간 이동·이주·전투·긴급 회복이 우선한다.
- 각 NPC는 서로 다른 주기로 4~12초 정도 쉬거나 주변을 산책한다. 산책 목적지를 매 틱 바꾸지 않으며, 도착하면 남은 시간에는 서서 쉰다. 이후 원래 직업 활동으로 돌아간다.
- 자유 시간의 약 40%는 제자리 휴식, 나머지는 주변의 충돌 없는 지점을 걷도록 시도한다. 주변이 막혀 산책 지점을 찾지 못하면 휴식한다. NPC별 고정 ID와 행동 순번을 사용하므로 매 프레임 난수를 다시 뽑지 않는다.
- 새 행동은 `Resting`(휴식, ID 9), `Wandering`(산책, ID 10)이다. 게임 상태 설명과 웹 모니터의 활동 이름·집계에 추가했다.

## 저장과 비용

활동 값 확장을 포함한 새 저장은 `GSE_WORLD 9`다. 버전 1~8도 읽으며 플레이어·호감도·NPC 신원·경제 정보는 유지한다. 경로와 자유 시간 타이머는 실행 중에만 관리하고 로딩 시 다시 계획한다. 저장된 작업 진행 중이면 현재 작업 위치를 우선 유지한다. 새 저장은 이전 실행 파일에서 읽을 수 없다.

경로 탐색은 시뮬레이션 틱당 최대 4회, 탐색당 최대 4,096개 노드, 경로당 최대 96개 경유지로 제한한다. 예산을 다 쓰면 다음 틱까지 안전하게 기다린다. 통행 가능 격자와 이웃 선분 검사는 크기가 제한된 공유 캐시를 사용한다. 매 프레임 모든 NPC의 경로를 다시 계산하지 않는다.

## 검증

`tests/NpcNavigationTests.cpp`에서 다음을 검사한다.

- 집 입구·작업 구역·다른 마을 사이 234개 경로가 실제로 도착하며, 모든 이동 선분이 충돌하지 않는지 검사.
- 목적지 변경, 도달 불가능한 목적지, 검색 예산 소진 시 안전한 대기, 경유지 수 제한.
- NPC 350명에서 서로 다른 산책 지점·작업 지점·휴식 선택, 시간 경과 후 네 방향 이동, 거래/작업 유지.
- 목적지를 향하는 동안 작업 지점이 바뀌지 않는지, 긴급 회복과 이주가 자유 시간보다 우선하는지 검사.
- 휴식/산책 활동을 포함한 버전 9 전체 저장 왕복과 실행 중 경로 상태 초기화.
- 선택적으로 실제 저장의 사본을 읽어 60초간 시뮬레이션한다. 실 플레이 저장은 쓰지 않는다.

실제 저장 사본의 60초 검사에서는 총 513개 NPC 기록을 처리했다. 이동·휴식·산책과 네 방향 이동을 확인했고 생존 NPC가 충돌체 내부로 이동하지 않았다. 이 환경에서 시뮬레이션 틱 p95는 1.07ms, 최대 2.44ms였다. 이는 AI 시뮬레이션 시간이며 렌더링 FPS가 아니다.

기존 `WorldSimulationTests`, `AffinityTests`, `MonitorSnapshotTests`와 Release/Debug 빌드도 확인했다. 기존 작업 완료 검사는 이제 NPC별 작업 지점과 자유 시간 상태를 명시적으로 설정한 뒤 동일한 생산·회복·깨달음 결과를 검사한다.
