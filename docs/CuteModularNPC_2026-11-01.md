# 귀여운 모듈 캐릭터 revision 4

사용자가 승인한 `Art/LowPoly_AgeOfEchoes/References/Approved_Cute_Modular_Concept.png`의 방향으로 사람 공용 파트 37개를 교체했다. 3등신, 둥근 사각 머리와 큰 눈·작은 코·미소, 조립식 몸체, 엄지가 있는 손과 둥근 부츠를 적용했다. 시안의 미세한 의상 장식은 게임에 맞게 단순화했다.

오브젝트/메시 이름, 슬롯별 고정 인덱스, 40개 조합, 공용 21개 바인드 뼈, 사람 클립 18개와 기존 전체 액션 144개의 키프레임을 보존했다. 망자에서 참조하는 사람 메시 7개를 함께 갱신했고 동물 6종과 환경 모델은 유지했다. 정적 파트·정적 라이브러리·리깅 사람 라이브러리·주민·망자의 GLB 및 관련 카탈로그를 동기화했다.

모델 품질 검사에는 닫힌 표면, 0 면적 삼각형, 정규화된 웨이트와 뼈 이름, 키프레임 해시 비교가 포함된다. 실제 주민 GLB를 재가져와 Walk/Run/Attack/Jump/Turn_L90의 스키닝 위치를 원본과 비교한다. 결과는 `Catalog/cute_modular_revision.json`에 기록한다.

게임의 평균 깊이 정렬은 큰 몸통 면과 작은 눈·벨트·갑옷 면의 겹침을 잘못 그릴 수 있다. 사람과 전투 캐릭터는 기존 `preciseDepth`를 활성화해 실제 겹침 위치의 깊이를 비교한다. 후보는 수평 경계 스윕/수직 경계로 거르고, 교차 영역은 고정 크기 스택 버퍼로 클리핑한다. 정렬 결과는 기존 포즈 캐시에 남으며 후속 포즈는 기존 단일 CPU 작업자가 준비한다. 교차 면의 순환은 안정된 순서로 처리하며 완전한 3D 깊이 버퍼와 동일하지는 않다.

`tests/NPCStylePreview.cpp`는 생산 렌더러로 네 가지 조합을 두 방향의 Idle/Run/Attack으로 크게 그리는 수동 시각 검사 도구다. `ProjectedDepthOrderTests`는 겹침/역방향 면/퇴화 면 보존과 여러 수평 군집의 깊이 순서를 검사한다. `ArtAssetTests`는 전체 카탈로그와 애니메이션 파일을 생산 로더로 검사한다.

재현 도구:

- `tools/Build-CuteModularNPC.py`: Blender에서 리깅 원본을 열어 실행. 기본은 `x64/perf/npc-toy-work` 검토본이며 `-- --publish`로 배포한다.
- `tools/Publish-CuteModularNPC.py`: 빌드 도구가 호출하는 내보내기/정적 원본 동기화/카탈로그 갱신 단계.
- `tools/Review-CuteModularNPC.py`: 배포된 리깅 원본에서 원본 액션·스킨 재가져오기를 검사하고 동작별 12장의 렌더를 만든다. 기존 로컬 원본 백업이 있으면 직접 비교하고, 없으면 카탈로그의 키프레임 해시를 사용한다.

미리보기 08번은 실제 Blender 모델 렌더이며 `References`의 승인 시안과 다르다. 09번은 실제 게임 캡처다. `Cute_Humanoid_*.gif`는 최신 네 조합의 키프레임 동작이다. 이전 revision의 미리보기는 이력으로 남긴다.

최종 검증: 37개 파트 모두 닫힌 표면·0 면적 삼각형 없음·유효 웨이트를 통과했다. 사용 중인 144개 액션을 포함해 원본 액션 데이터블록 154개의 키프레임 해시가 일치했다(기존 미사용 액션 10개 포함). 주민 GLB의 5개 클립 재가져오기 최대 위치 차이는 약 0.000704mm였다. `ArtAssetTests`, `ProjectedDepthOrderTests`, 실제 렌더러 시각 검사, Release/Debug 빌드를 통과했다.
