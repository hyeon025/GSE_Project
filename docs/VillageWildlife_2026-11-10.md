# 마을 밀도와 현장 동물

## 플레이어 사거리와 공격 복구

마을 화면에서도 기존 전투의 `LevelOne::Range`, `Damage`, `Cooldown` 설정을 공유한다. 플레이어 발밑에 실제 판정 범위와 같은 사거리 원을 표시하고, 범위 안의 시야가 트인 위험 동물을 자동 조준해 투사체를 발사한다. `F`는 초식동물도 포함해 수동 공격한다. 평범한 주민은 자동 공격하지 않는다. 대화·메뉴가 열린 동안에는 새 자동 발사를 중단한다.

공격 시 플레이어의 Attack 키프레임, 금빛 투사체, 명중 빛과 동물 체력 변화를 표시한다. 투사체는 장애물에 막히며 실제 동물과 충돌했을 때만 피해·처치 보상을 적용한다. 경작지 화면으로 전환할 필요가 없다. 비행 중 투사체와 짧은 공격 모션은 세션 상태다.

`WorldCombatTests`에서 자동/수동 발사, 동일 사거리, 대기시간, 범위 밖·장애물 차단, 초식동물 자동 공격 제외, 명중·처치 보상을 검사했다. `WorldCombatRenderTests`는 실제 GL 화면에서 사거리 원·투사체 노드와 공격 모션을 렌더링하고 사라진 투사체 노드도 제거되는지 확인한다.

- 집 간격을 112에서 160으로 늘리고 마을 반경을 850으로 넓혔다. 화면의 도로, 충돌체, NPC 경로 격자, 집 입구를 같은 간격으로 맞췄다. 사냥·명상 작업 지점도 새 주택과 겹치지 않는 외곽으로 옮겼다.
- 새 게임 주민은 마을당 50명에서 24명(7개 마을 총 168명)으로 줄였다. 기존 저장의 주민·이름·호감도·경제 기록은 유지한다. `layoutVersion 2`로 최초 변환할 때 집과 주민을 넓어진 배치에 옮기며, 50명 시절의 저장도 읽는다. 이후 재실행마다 재배치하지 않는다.
- 경작지 입장 버튼을 제거했다. 기존 경작지 전투 저장은 비활성 상태로 시작하며 F1도 별도 전투로 전환하지 않는다. 스토리 전투는 유지한다.
- 각 마을 주변에 늑대·멧돼지·곰·사슴·염소·토끼를 각 1마리씩, 전체 42마리로 제한해 배치한다. 초식동물은 가까운 플레이어에게서 도망치고 위험한 동물은 감지 범위에서 추격·공격한다. 추격 거리와 서식지 이탈 범위를 제한한다. `F`로 가까운 동물을 공격할 수 있으며 체력 막대와 처치 보상이 있다.
- 쓰러진 동물은 45초 뒤 플레이어와 충분히 떨어졌을 때 서식지에 돌아온다. 동물 개체·체력·재등장 타이머는 세션 단위이며 저장을 다시 불러오면 새로 배치한다. 주민 저장에는 동물을 섞지 않는다.
- 동물은 모델 앞쪽 축(glTF +Z → 게임 -Y)에 맞춰 연속 각도로 회전한다. 추격 중에는 플레이어를, 일반 이동 중에는 이동 방향을 바라본다. 기존 스토리 전투 동물도 같은 방향 계산을 사용한다.
- 멀리 있는 동물은 이동 계산을 줄이고, 기존 NPC와 경로 탐색 예산·비동기 포즈 캐시를 공유한다. 웹 모니터에 현장 동물 수를 실제로 집계한다.

`WildlifeTests`에서 주민 수, 동물 42개, 유효 배치, 전 방향 회전, 추격/도망, 피해, 공격 대기시간, 처치·재등장, 예전 밀집 저장을 검사했다. 변경된 배치에서도 `NpcNavigationTests`의 234개 경로, `WorldSimulationTests`, 호감도·모니터 검사를 통과했다. 실제 게임 렌더링 경로를 사용하는 숨긴 GL 창에서 180프레임 이동·동물 표시를 확인했고 Release/Debug 빌드를 완료했다. 실제 플레이 저장은 검사 중 덮어쓰지 않았다.
