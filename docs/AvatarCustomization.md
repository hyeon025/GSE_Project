# 플레이어 프로필과 아바타 꾸미기

월드 화면 상단의 **꾸미기**, 또는 전투 HUD의 **꾸미기** 버튼으로 전용 창을 엽니다.
창이 열려 있는 동안 월드와 전투 시뮬레이션은 일시 정지합니다.

- 프로필: 이름, 한마디, 성별 표시. 성별은 **여성 고정**이며 변경할 수 없습니다.
- 머리색 8종, 피부색 5종, 헤어 5종, 표정 6종, 의상 6종, 옷 색 13종을 클릭해서 선택합니다.
- 왼쪽에 실제 Blender 모델을 미리 표시하며 **회전** 버튼으로 네 방향을 확인합니다.
- 이름과 한마디 입력란을 클릭하면 기존 내용이 선택됩니다. 문자 입력, Ctrl+A, Ctrl+V,
  Backspace를 지원합니다. Tab으로 입력란을 전환하고 Enter로 입력을 마칩니다.
- 이름은 필수이고 한마디는 비워도 됩니다. 길이는 Windows UTF-16 기준 이름 16자,
  한마디 32자입니다. 보조 평면 문자는 두 자리로 계산하며 중간에서 자르지 않습니다.
- **적용**은 변경 내용을 게임에 반영하고 저장합니다. 저장에 실패하면 기존 프로필을
  유지하고 창에 오류를 표시합니다. **취소** 또는 Esc는 편집 내용을 버립니다.

## 구현과 호환성

`PlayerProfile.h`는 프로필, 외형 선택값, 입력 검증과 직렬화를 담당합니다.
성별은 수정 가능한 데이터가 아닌 고정 규칙입니다. `Art::Library::PlayerRecipe`는
여성 머리 파트와 선택한 헤어·의상을 조립합니다. 외형은 월드와 전투에 공통 적용됩니다.
머리색·피부색·옷 색은 기존 인스턴스 팔레트를 사용하므로 색상별 메시를 만들지 않습니다.
표정과 애니메이션은 기존 포즈 캐시 및 작업 스레드를 사용합니다.

저장 형식은 `GSE_WORLD 7`입니다. 기존 1~6 버전은 월드와 NPC를 유지하면서 기본 여성
프로필로 불러옵니다. 신규 프로필은 별도 `PROFILE 1` 블록으로 기록하며 잘못된 값이나
중단된 입력은 거부합니다. 성별 선택값은 저장 파일에도 없습니다. 사망 시 프로필은 유지됩니다.

## 확인 안내

요청에 따라 빌드와 게임 실행은 진행하지 않았습니다. 직접 빌드한 후 각 선택의 미리보기,
적용/취소, 전투 중 편집, 재실행 후 유지, 기존 저장 불러오기를 확인해 주세요.
`tests/PlayerProfileTests.cpp`에는 문자열·외형 저장 복원, 손상 데이터 거부,
Unicode 길이 제한과 삭제 검사를 추가했습니다. `tests/ArtAssetTests.cpp`에는 모든
헤어·의상 조합이 여성 머리를 유지하는 검사를 추가했습니다. 두 테스트도 실행하지 않았습니다.
