# 걷기와 머리카락 표시 수정

2026-11-09 후속 수정: [GPU 깊이 판정, 연속 보행 및 프레임 지연 검증](CharacterRendering_2026-11-09.md). 아래는 이전 수정 당시의 기록이다.

## 확인한 원인

- `CharacterMotion`이 이동량으로 보행 위상을 계산하고 있었지만, GLB 재생은
  `world.time`을 사용했다. NPC와 플레이어의 속도 차이·충돌·재출발이 발동작에 반영되지 않았다.
- NPC 위치는 사회 시뮬레이션의 0.1초 간격 위치를 그대로 화면에 표시했다.
- 비동기 포즈 대기 중 사용할 직전 포즈가 같은 외형의 캐릭터끼리 공유됐다.
  캐릭터별 보행 위상을 사용하면 서로 다른 시점의 자세를 가져올 수 있는 구조였다.
- 꾸미기 미리보기에는 `preciseDepth`가 빠져 있었다. 삼각형 중심 깊이만으로 정렬하면
  큰 피부 면이 더 가까운 작은 머리카락 면을 덮을 수 있다.

## 변경

이동한 거리에 따라 보행 주기를 진행하고, 정지 중에는 위상을 보존한다. Walk/Run은
각 클립 길이에 맞춘 정규화된 주기를 공유한다. 게임의 이동 속도와 마을 간 거리는 유지한다.
주기당 이동 거리는 게임 단위의 Walk=85, Run=92이며, 이는 게임 표시용 보폭이다.
Blender의 미터 단위 발 궤적과 완전히 일치시키는 발 고정/IK는 구현하지 않았다.

NPC의 위치와 보행 위상은 사회 시뮬레이션의 이전/현재 상태 사이를 보간한다.
최대 한 틱(0.1초)의 표시 지연을 사용하는 방식이며 충돌·전투·저장 좌표는 바꾸지 않는다.
보행 포즈는 원본 기준 30Hz로 샘플링하고, 다른 클립은 기존 15Hz를 유지한다.

비동기 직전 포즈는 캐릭터별로 관리한다. 최종 메시 캐시는 기존대로 외형·방향·포즈가
같으면 공유하며, 캐릭터 ID는 메시 키에 넣지 않는다. 샘플 개수도 키에 포함해 15/30Hz의
같은 프레임 번호가 다른 자세인데도 충돌하는 것을 방지한다. 기존 192MiB/1,024포즈 제한과
단일 작업자, 120샘플 상한을 유지한다. 포즈 수 증가에 따른 실제 성능 영향은 미측정이다.

팔레트를 사용하는 캐릭터는 호출 위치와 관계없이 정밀 깊이 정렬을 사용한다.
꾸미기 미리보기에도 이를 명시하고, 투영 캐시 버전을 2로 올려 이전 결과를 재사용하지 않는다.
원본 `.blend`/GLB의 파트·본·키프레임은 변경하지 않았다.

## 원본 데이터 검사

`tools/Inspect-CharacterGeometry.py`를 Blender 백그라운드에서 실행했다.
게임 실행·이미지 렌더·원본 저장·내보내기는 수행하지 않는 읽기 전용 검사다.
로그는 로컬 `x64/perf/character-source-audit.log`에 기록했다.

여성/남성 머리 각각의 정수리·관자 상단 61개 정점을 5종 헤어와 비교했다.
총 610개 검사점에서 머리카락 덮임 누락과 안쪽으로 뒤집힌 교차 면은 발견하지 않았다.
전체 머리 표면이나 모든 애니메이션 프레임을 보증하는 검사는 아니다.

여성 머리의 정면 바인드 자세에서 삼각형 중심 정렬과 픽셀별 깊이를 수치 비교했다.
0.25월드 단위 간격의 검사점 중 피부가 머리카락을 잘못 덮는 수는 다음과 같았다.

| 헤어 | 기존 중심 정렬 | 정밀 정렬 | 머리카락 검사점 |
| --- | ---: | ---: | ---: |
| 숏컷 | 43 | 0 | 7,329 |
| 단발 | 86 | 17 | 8,497 |
| 긴 머리 | 84 | 18 | 9,134 |
| 땋기 | 43 | 1 | 9,005 |
| 넘김 | 36 | 0 | 7,329 |

정밀 정렬도 교차하는 면을 분할하지 않는 기존 페인터 방식이므로 일부 오류는 남는다.
완전한 픽셀 깊이 버퍼와 같은 결과를 보장하지 않는다. 위 수치는 원본 좌표의 수치 검사이며
실제 게임 화면 캡처나 전체 의상을 포함한 시각 검증 결과가 아니다.

## 직접 확인할 항목

요청에 따라 게임 빌드·실행·C++ 회귀 테스트 실행은 진행하지 않았다.
`CharacterVisualTests`에 이동량 기준 보행·정지·주기 경계 보간 검사를,
`NpcPresentationTests`에 NPC 보간과 모델 좌표 보존 검사를 추가했다.

직접 빌드 후 플레이어의 걷기/달리기/충돌 후 이동, NPC의 느린 이동과 정지,
꾸미기 창의 5종 헤어를 네 방향에서 확인한다. 화면에서 큰 누락이 계속되면 해당 방향과
헤어·의상 조합을 기준으로 교차 면 처리 또는 캐릭터 전용 깊이 렌더링을 후속 조사한다.
